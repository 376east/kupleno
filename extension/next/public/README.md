# Куплено

Загрузите эту папку через «Загрузить распакованное расширение» на странице расширений Chromium-браузера. Откройте Куплено, загрузите JSON/CSV или перейдите в «Магазины». Для сбора нужен вход на сайт магазина и разрешение на его домен.

Сбор может завершиться частично. Уже сохранённые покупки останутся в журнале. Установка и сбор проверены с тестовыми ответами магазинов.

Перед обновлением сохраните резервную копию. Используйте прежнюю папку установки для сохранения ID. Не удаляйте старое расширение ради проверки новой версии.

Документация и известные ограничения: https://github.com/376east/kupleno
